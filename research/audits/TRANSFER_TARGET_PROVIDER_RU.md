# Целевой адаптер переноса: текущая проверенная граница

Семантический владелец `cross_embodiment_transfer` — Experiment 06; источник `so101_source_learning` — 04. Новые result получают project_id/source_project_id через общий реестр v2. Один UUID навыка сохраняется, целевая версия увеличивается, source6D не переименовывается в ROSMASTER9D. Это компонент полного переноса; создание канонического целевого train/dev/sealed-корпуса, обучение официального ACT, полный candy→box rollout, API/UI и выбор deploy остаются следующими этапами.

`explorer_shared.skill_transfer.load_source_trace(path, expected_sha256)` читает immutable source manifest `explorer_skill_transfer_source_trace_v1`: UUID/version, исходный контракт `so101_follower_calibrated_position6_v1`, шесть именованных native действий, task_type, original split/group IDs, frames[phase_id/reference(object|goal)/native_action6], source_files_sha256. Метод явно `SCRIPTED_SIM` или `QUALIFIED_SOURCE_MODEL`. Стационарный hold/trajectory не становится object skill. Квалифицированному источнику нужны сохранённые model/processors/evaluation SHA и независимые closed-loop object run IDs; соответствующие SHA должны реально присутствовать в проверенном source inventory. Источник с 12 координатами требует явного bimanual role plan, не обрезается до первой руки. При наличии source_rgb_file сохраняется исходный RGB; совпадение исходных пикселей с выдаваемым за target render кадром запрещается.

`TaskRelativeMapper(source_chain, target_chain, source_coordinates, target_coordinates, source_profile=..., source_aperture=..., target_aperture=..., task_frames=..., target_low=..., target_high=..., collision_checker=...)` использует именованный source FK, отдельные object/goal SE(3) регистрации, метрическую апертуру, target IK и неизменённый factory servo-coordinate adapter. Результат `plan(frame, observation)` всегда содержит target_action9. Нужен буквальный preceding_command9, его нельзя собрать из measured joints + odometry. Нейтральные vx/vy/wz — явные команды с сохранёнными каналами. Отсутствующая/невалидная геометрия не превращается в нули или clip.

Если эффект за пределами текущего arm workspace либо блокирован столкновением, планировщик ищет достижимую целевую позу базы на наблюдаемой occupancy map, строит A* путь и выдаёт ограниченную body velocity при сохранении последних шести команд руки. Неизвестные клетки и пространство за картой заняты; учитывается площадь клеток и радиус ROSMASTER. Нет карты/проходимого пути/достижимой позы — конкретная A-причина. Ни один вызов не отправляет аппаратные команды.

`record_target_trial(bundle, mapper, target_provider, folder, target_version=..., target_skill_spec=..., seed=..., max_steps=...)` принимает только явно nonphysical provider. До шага физики fsync-сохраняются целевой кадр, полное исходное observation и request; после — dispatch с действительными 9 координатами, native integration state, measured qpos/qvel, clocks и independent evaluator. Частичный сбой сохраняет request/RGB/result с причиной. Источники повторно хешируются; повторное использование существующего каталога запрещено. Renderer frame IDs уникальны; в настоящей физике frame stamp должен предшествовать dispatch в одном boot/clock. Полные стадии проверяются по target SkillSpec, команды и таймеры сами по себе не доказывают grasp/place. Negative и incomplete trials остаются 0 expert. Development/sealed не допускаются в optimizer, source split сохраняется. MOCK provider никогда не становится доказательством реальной симуляционной задачи.

`explorer_shared.skill_transfer_mujoco.MuJoCoTargetProvider(env, target_urdf_sha256=..., mesh_files={path:SHA}, phase_evidence_map={phase:[criterion,...]}, navigation_map_provider=None)` получает готовый env через injection. Не импортирует пакеты экспериментов. Читает настоящий MuJoCo model/data, проверяет CAD SHA, сохраняет engine/source/model identity, рендерит ROSMASTER и исполняет конечные шаги существующего env. Для mobile env используются его реальные wheel dynamics; для исходного stationary fixture сохраняются три явных нейтральных base канала, а ненулевая навигация честно отклоняется. Это не пользовательский arm-only режим и не альтернативный контракт.

Collision provider проверяет дискретные положения участка по исходной контактной модели с шагом ≤0.02 rad. Его receipt прямо указывает sampled_segment_checked=true, continuous_segment_checked=false, gripper_segment_geometry_checked=false; finger/object contact разрешён намеренно. Визуальный CAD сохранён, контактные примитивы/свойства исходной MuJoCo модели являются оценочными. Ни непрерывная теорема collision-free, ни физическая квалификация из этой проверки не выводятся. Полный mobile outcome нельзя заменить object-only pass. Feedback и force физического робота не включаются и не синтезируются этим кодом.

22 целевых теста прошли за 6.82s, включая migration/calibration regressions. Из них две настоящие MuJoCo проверки: целевой ROSMASTER RGB/9D/finite dispatch/independent negative object outcome и 16 шагов wheel actuation. За 1 sim second база прошла 0.06460348799123872 m; object/full-task success=false. Кадр целевого ROSMASTER фактически просмотрен. Ни обучение, ни физическое движение не выполнялись. SCRIPTED_SIM fixture содержит лишь технический source trace, а не освоенный SO101 candy skill.

Raw evidence: `/tmp/explorer-transfer-atomic-final-20261026`, итоговый private receipt `~/.local/state/explorer-work/transfer-target-provider-qualification-20261026.json`. Зафиксированы source/module/CAD/model SHA и все wheel dispatches. Для следующего этапа нужны полный явно scripted source reference, положительный независимый target object outcome, канонический target dataset с global split guards и вызов injected shared official ACT backend. Реальный квалифицированный source04 object policy остаётся отдельным C-входом; он не блокирует продолжение software/SIM разработки.
