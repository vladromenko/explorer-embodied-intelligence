# Начальное состояние будущего stationary CAD trial

`explorer_shared.sim_initial_state` — новый helper для **будущего** захвата после reset и до первого observe/dispatch. Он не меняет существующие `MuJoCoTargetProvider`/`record_target_trial`, старые V9 файлы или их PARTIAL. Поддерживается только явный stationary `ManipulationEnv` profile с шестью servo и нейтральными base3 в интерфейсе provider. Неизвестные env/evaluator/provider fields, mobile, внешние callbacks/plugins/threadpool отвергаются.

`capture_initial_trial(provider, *, scenario, source_bindings)` возвращает `InitialStateBundle(document, payloads)` с `.sha256`. Источники задаёт доверенный caller как role→`{path,sha256}`; они проверяются и сохраняются байт в байт. Bundle содержит NPY float64 `mjSTATE_INTEGRATION`, independent-copy `mj_embedAssets`→MJB, исходный XML/CAD, typed JSON env/evaluator/provider state, производные geom/body/velocity arrays, warning counters, visualization options и состояния реально существовавших RNG. Никаких pickle/eval/source-driver execution. Значения ndarray сохраняют dtype/shape/bytes, tuple/set и большие RNG integers не теряются. Обращение к lazy `.np_random`/space properties запрещено: неиспользованные generators не создаются.

`save_initial_bundle(bundle, new_folder)`/`load_initial_bundle(folder, expected_sha256=...)` сохраняют/проверяют immutable bounded file graph. `restore_initial_trial(provider, bundle, *, expected_sha256, expected_source_bindings)` принимает уже созданный доверенным кодом SIM provider. SHA payloads, source/classes, critical Python/NumPy/MuJoCo runtime bytes, model/XML/assets/config/native ABI и все mutable/RNG структуры проверяются **до** первого `mj_setState`. JSON-supplied filesystem paths не открываются. Native state восстанавливается один раз на стартовой границе; последующие действия идут через настоящую finite physics. Original и replay SIM clock IDs различаются и связываются receipt.

`mjSTATE_INTEGRATION=16383` в установленном MuJoCo3.17 включает time/qpos/qvel/act/history/warmstart/ctrl/applied forces/eq_active/mocap/userdata/plugin, но не все derived/render/diagnostic buffers. Поэтому helper сохраняет конкретные массивы, которые читает этот profile, и явно оставляет RGB render reexecution UNQUALIFIED. Запись MJB использует `mj_embedAssets` на независимой копии согласно официальному `mujoco.h`, исходная model/settings не меняется.

Runtime binding охватывает текущие Python executable/version/ABI, NumPy/MuJoCo modules, NumPy shared libraries, libmujoco и helper source. Это конкретный source/runtime pin для нового PID на соответствующей среде; весь OS/transitive environment остаётся PARTIAL. Сохранение initial state само по себе не доказывает динамическую или pixel parity. Отдельный `scripts/qualify_sim_initial_state.py` предназначен для finite CPU/no-render CAD→snapshot→new PID→same12commands/RNG/evaluator parity, с сохранением любых неуспехов. Его запуск требует согласованного ресурсного окна. Исходные controller files и физические устройства не затрагиваются.
