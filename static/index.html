3. Подготовить обучение











Train / validation / test






Train — оставшиеся данные. Validation — оценка во время обучения. Test — только итоговая оценка после завершения; ни test, ни validation не участвуют в нормализации. Для трёх выборок нужны минимум три независимые группы. Фактические числа покажет проверка ниже.




Параметры обучения и сохранения





Resume сохраняет тип модели, схему, выборки и состояние optimizer. Steps задаёт итоговый шаг, он должен быть больше шага checkpoint. Веса и данные автоматически не публикуются.


SAM и MLflow
SAM размечает сохранённый raw отдельно. XYZ/depth/размеры unknown без проверенной геометрии. MLflow пишет реальные метрики и конечный checkpoint; недоставленные события остаются в буфере.




4. Checkpoint и запуск политики
Движения должен предсказывать сохранённый checkpoint. Автоматическая проверка успешного захвата отсутствует; запуск требует оператора, свободной аппаратуры и проверенных пределов.
