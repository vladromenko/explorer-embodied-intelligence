Выборки и эпизоды

Train — оставшиеся данные. Validation — оценка во время обучения. Test — только итоговая оценка после завершения; ни test, ни validation не участвуют в нормализации. Для трёх выборок нужны минимум три независимые группы. Фактические числа покажет проверка ниже.

Параметры обучения и сохранения

Resume сохраняет тип модели, схему, выборки и состояние optimizer. Steps задаёт итоговый шаг, он должен быть больше шага checkpoint. Веса и данные автоматически не публикуются.

Разметка SAM 3

Разметка работает с сохранёнными кадрами и не замедляет запись. При занятости GPU задача ожидает.

Выберите checkpoint

Технические модели скрыты. Движения возможны только после явного запуска. Для SAM+VLA частота live-исполнения ещё требует операторской проверки: слишком старое наблюдение останавливает отправку действия.

Настройки лаборатории

Оборудование

Подключение камер не открывает servo bus и не включает torque. Занятые устройства не перехватываются.

Режим разработчика

Синтетические кадры служат только для проверки программы. Они не являются изображениями камер и не используются обычным обучением.
