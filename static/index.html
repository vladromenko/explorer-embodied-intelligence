3. Разметка и обучение
Настройки SAM / камеры / MLflow
SAM не измеряет depth, XYZ, размер или усилия. Геометрия сейчас unknown: установка камер требует независимой проверки. Числовые tracking ID не подаются политике.
MLflow: отдельные DB/artifacts, метрики реального loop. При сбое доставки события остаются в локальном буфере.
Если GPU/RAM заняты, задача ожидает. Raw-запись не вызывает SAM. Для обучения нужны отдельные эпизоды train/validation и полностью совпадающие sidecar-аннотации.


4. Checkpoint и запуск политики
Движения должен предсказывать сохранённый checkpoint. Автоматическая проверка успешного захвата отсутствует; запуск требует оператора, свободной аппаратуры и проверенных пределов.
