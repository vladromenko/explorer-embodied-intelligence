# Показы ROSMASTER

Интерфейс: `/experiments/02`. Штатный keyboard/gamepad и моторный путь Nano
сохранены. Новая панель передаёт разрешённые рабочие операции через legacy bridge;
конфигурацию контроллера не записывает.

Завершённый native episode передаётся через `explorer_shared.mobile_records`:
неизменяемый архив, SHA исходных JSONL/JPEG и проверка завершённого UUID.
`explorer_shared.mobile_adapter` строит причинно упорядоченный девятикоординатный
набор: шесть servo endpoints в градусах, vx/vy в м/с, wz в рад/с. Состояние руки —
история команд/оценка траектории, не измеренные углы. Время источника не
переименовывается в подтверждённую экспозицию или синхронизированные часы.

Worker импортирует официальный LeRobot v3 с обратным чтением. ACT обучается
по явно выбранному пригодному успешному показу; failed/unknown сохраняются
для анализа. Штатный recorder сейчас отклоняет запуск из-за существующего
LOW_POWER. Эта настройка не менялась. Реальная запись/import после заряда,
9D shadow и физическое выполнение обученной мобильной политики ещё не проверены.

См. `_registry/evidence/`, `research/protocols/` и общий аудит незавершённых
функций. Не путать импорт/обучение с подтверждённым захватом предмета.
