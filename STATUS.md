# SO-101 — обучение SmolVLA + SAM 3 + MLflow

2026-11-03. Работа выполняется на homebrain в самостоятельном проекте.

- Выполнено: hostname/cwd, правила, процессы, USB-владельцы, RAM/диск/порты, адреса.
- Ресурсы: камеры/servo bus заняты параллельным экспериментом. При аудите MemAvailable ~3.6 GB, чужой SAM/сервер ~8 GB RSS. Не останавливаем и не открываем устройства.
- Свободные порты для лаборатории: 8020 (UI), 5020 (MLflow); перед запуском повторно проверяем.
- В работе: независимая среда, raw recorder/UI, SAM sidecars/adapter, SmolVLA train/inference, MLflow, программные проверки.
- Нельзя считать выполненным: аппаратная запись, актуальная camera/hand-eye геометрия, GPU smoke и качество захвата. Они требуют свободных ресурсов и оператора.
