# Explorer — фактическое состояние

Единый приватный Git создан; старые исходники и Git bundle сохранены. Control Center работает на NX: http://homebrain.local:8088. Три узла online; реальные камеры Pi/Nano, долговечные события, запись и проверенная передача кадров. Пройден CPU optimizer/save/reload для PPO и официального ACT на NX. Полный физический навык пока не валидирован.

Настройки существующего контроллера ROSMASTER сохраняются без изменений. Владелец разрешил автоматическое физическое исполнение при видимости руки/машины на камере Pi либо подтверждённом присутствии. Новых настроек безопасности не добавляется.

Исследовательские и аппаратные результаты учитываются отдельно. Литературный обзор не завершён: текущие точные счётчики в research/literature/REVIEW_STATUS.json. Инженерная симуляция reach не заменяет носок→корзина или физический handover.
