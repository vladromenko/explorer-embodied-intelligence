Mac для runtime не требуется. Ветки предметной симуляции, прямого teaching и
ACT-transfer/handover интегрированы. Центральный runtime `80eae2e` проверен через
авторизованные HTTP-страницы/API; основная ветка содержит также последующую

Через действующую очередь прошли `996326dac4c24adaa181ef9723289d11`

native replay error 0.0. Более длительный job `ef04eed441da4ecf9d6e7e9a981071e3`

на момент записи выполняется сбор исходных показов. Итога ещё нет.

Мастер показов подключён к исходным импортам и неизменяемым разборам оператора;
он различает неизвестный исход, неудачу, неполные фазы и одобренный полный показ.
Движение шасси не выполнялось, новые настройки контроллера не записывались.
Полная приёмка мастер-промпта остаётся открытой.

Единый приватный Git создан; старые исходники и Git bundle сохранены. Control Center работает на NX: http://homebrain.local:8088, код входа `1234`. Raspberry Pi подключается непосредственно к домашнему Wi-Fi: `ssh explorer-pi`. Реальные камеры, долговечные события, запись и проверенная передача кадров работают. Пройдены CPU optimizer/save/reload для PPO/ACT и отдельная проверка GPU ACT на NX. Фактически проверено продолжение GPU ACT после смены релиза: сохранённый шаг25 →240, исходный commit задания сохранён. Физический навык с предметом пока не валидирован.

Настройки существующего контроллера ROSMASTER сохраняются без изменений: шесть контрольных SHA совпадают. **Движение шасси запрещено владельцем на время зарядки.** Для рук действует разрешение на автоматическое исполнение при видимости руки/машины на камере Pi либо подтверждённом присутствии владельца. Новых настроек безопасности не добавляется.

Литературный обзор содержит 102 проверки полного текста, из них 35 глубоких; реестр и первоисточники находятся в `research/literature/`. Исправленный CPU reach-пилот: baseline 0/6, teacher 6/6, ACT 1/6; это симуляция, не работа с носком или handover. Offline world-model реально обучена и сравнена с persistence; улучшения основных метрик пока нет. H1–H5 не проверены.

После перезапуска Nano GPU не инициализируется на уровне драйвера. Отдельный CPU-приёмник восстановил свежие RGB-D данные; При включённом владельцем свете RGB проверен: изображение нормальное; прежняя темнота объяснялась выключенным светом. Старый неисправный GPU-unit обратимо замаскирован с точной частной резервной копией; камера, контроллер и MCU не перезапускались. Подробности — `00-control-center/docs/NANO_CPU_CAMERA_CACHE_RU.md`.

Зарядное устройство CHD-12620: 12,6 В × 2 А. Руководство M3 Pro требует выключить главный выключатель при зарядке; программная настройка зарядки при включённом компьютере не найдена. Внешний APFS-диск 1 ТБ не форматировался; рабочие данные находятся на NVMe NX. Проверена полная копия центральных данных/весов: 287 payload-файлов,1,125ГБ; независимая копия на Mac и отдельное полное восстановление с проверкой SHA всех файлов. Копия не содержит ОС/venv и не заменяет резервирование удалённых оригиналов.
