# Explorer — фактическое состояние

Единый приватный Git создан; старые исходники и Git bundle сохранены. Control Center работает на NX: http://homebrain.local:8088, код входа `1234`. Raspberry Pi подключается непосредственно к домашнему Wi-Fi: `ssh explorer-pi`. Реальные камеры, долговечные события, запись и проверенная передача кадров работают. Пройдены CPU optimizer/save/reload для PPO/ACT и отдельная проверка GPU ACT на NX. Физический навык с предметом пока не валидирован.

Настройки существующего контроллера ROSMASTER сохраняются без изменений: шесть контрольных SHA совпадают. **Движение шасси запрещено владельцем на время зарядки.** Для рук действует разрешение на автоматическое исполнение при видимости руки/машины на камере Pi либо подтверждённом присутствии владельца. Новых настроек безопасности не добавляется.

Литературный обзор содержит 102 проверки полного текста, из них 35 глубоких; реестр и первоисточники находятся в `research/literature/`. Исправленный CPU reach-пилот: baseline 0/6, teacher 6/6, ACT 1/6; это симуляция, не работа с носком или handover. Offline world-model реально обучена и сравнена с persistence; улучшения основных метрик пока нет. H1–H5 не проверены.

После перезапуска Nano GPU не инициализируется на уровне драйвера. Отдельный CPU-приёмник восстановил свежие RGB-D данные; исходный цветной кадр почти чёрный; владелец подтвердил, что в комнате выключен свет. Старый неисправный GPU-unit обратимо замаскирован с точной частной резервной копией; камера, контроллер и MCU не перезапускались. Подробности — `00-control-center/docs/NANO_CPU_CAMERA_CACHE_RU.md`.

Зарядное устройство CHD-12620: 12,6 В × 2 А. Руководство M3 Pro требует выключить главный выключатель при зарядке; программная настройка зарядки при включённом компьютере не найдена. Внешний APFS-диск 1 ТБ не форматировался; рабочие данные находятся на NVMe NX. Проверена резервная копия метаданных с отдельным восстановлением; она не содержит всех видеоданных и весов.
