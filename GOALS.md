# Цели Explorer

Единая работа по исходному master-prompt продолжается; эта страница служит
индексом требований и не заменяет его. Полная редакция Homebrain хранится в
`~/.local/state/explorer-work/master-prompt.md`; предыдущие журналы сохраняются.

Результат: автономная распределённая лаборатория01–06 с настоящими UI/backend,
записью, датасетами, обучением, проверкой, Skill memory, переносом, кооперацией,
восстановлением и воспроизводимыми H1–H5 исследованиями. Mac не нужен runtime.
Все критерии закрываются проверяемыми evidence в едином
[_registry/acceptance.json](_registry/acceptance.json), включая матрицу01–06.

Неизменные ограничения: агент не двигает шасси **или руки**; реальные движения
только в отдельном текущем наблюдаемом пользовательском тесте. Исходные6
ROSMASTER configs, firmware, limits, watchdogs и выключенный servo feedback
не меняются. Command estimate не становится measured; неизвестное остаётся
unknown/null/mask. Нового Python `continue` нет. Raw scientific originals,
отрицательные исходы, старые IDs/SHA/splits не переписываются.

Software integration, физический навык и научный claim принимаются раздельно.
SIM/mock/loss/один API или инфраструктурный этап не завершают master-prompt.
Текущие факты — [STATUS](STATUS.md), открытые этапы — [PLAN](PLAN.md),
решения — [DECISIONS](DECISIONS.md), действия владельца —
[PHYSICAL_CHECKLIST](PHYSICAL_CHECKLIST.md).
