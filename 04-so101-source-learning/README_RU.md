# 04 · SO101 source learning

Каноническая страница — `/experiments/04`; прежняя `/learning/so101` перенаправляет
сюда. Две руки и камера подключены к Raspberry Pi, обучение и skill memory —
на Homebrain. Семантическая роль `so101_source_learning`, numberingv2.

Выберите/отредактируйте SkillSpec и подтвердите версию; задайте сцены, сессии,
экземпляры предмета и split. Подготовьте контекст записи, отдельно включите
наблюдаемое телеуправление и сохраните целый показ. Разберите исходное видео
и временные шкалы leader/requested/accepted/dispatched/measured, фазы и итог.
Только прошедшие серверный admission оригиналы входят в общий immutable
агрегат этой версии. Все принятые совместимые показы используются вместе;
train/development/sealed разделяются по независимым группам и RGB content.

ACT остаётся вариантом по умолчанию. Diffusion доступен только для отдельно
квалифицированного CPU/native6 профиля; обе модели учатся на том же source
контракте. Текст и фазовые подписи не становятся языковым входом модели.
Save/reload и ошибка на development не доказывают предметный навык. Raw replay,
shadow и отдельный наблюдаемый физический rollout различаются явно.

Сохраняются исходные IDs, калибровки и нормированные единицы; это не градусы.
`use_degrees=False`; официальный hardware robot/replay CLI не запускается
автоматически. Существующие моторные калибровки повторно не настраиваются.
Перенос проверенного навыка на ROSMASTER относится к06, ручной leader→ROSMASTER
— к03, кооперация с отдельными действиями двух роботов — к05.

Текущий статус — [STATUS.md](../STATUS.md), физическая подготовка —
[веб-чеклист](../EVENING_CHECKLIST_RU.md). Полный навык с предметом пока не принят.
