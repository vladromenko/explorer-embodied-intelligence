# 04: показ, запись и отдельный разбор

Новая панель использует подтверждённый SkillSpec и существующий backend
`/api/lab/demonstrations`. Она ещё не развёрнута на production.

1. В мастере выберите навык и версию, создайте сессию сцены, выберите вариант и
   экземпляр предмета. Подготовка контекста и нового показа не включает руки.
2. В отдельном текущем наблюдаемом USER тесте покажите свежий исходный кадр
   единственной Pi Logitech и подтвердите три условия наблюдения. Разрешение и
   начало повторения — разные кнопки. Recenter использует возвращённый epoch.
3. Начните запись. Пауза сохраняет raw и исключает соответствующие samples из
   обучения. Фазы отмечаются отдельно. Отмена сохраняет исходники.
4. Завершите запись с явным success/failure/unknown. Finish не посылает STOP и
   не ставит импорт в очередь. Отдельный scoped STOP завершает своё управление.
   Смена native owner до завершения честно помечает запись interrupted.
5. Просмотрите сохранённый исходный JPEG. Отдельно разрешите перенос конкретного
   архива либо отклоните его. Статус immutable import job читается из общей
   очереди по точным archive/review SHA. Поздний reject сохраняет прежнее задание,
   но закрывает допуск по предыдущему решению.
6. После импорта используйте существующий мастер для привязки и полного разбора
   исходных фаз; source approval не означает приёмку целого навыка. Обучение,
   offline shadow и физический тест модели остаются отдельными действиями.

Обновление статуса и другая вкладка не присваивают grant/epoch. При уходе из
окна закрывается только локально известный scope; возвращение ничего не
восстанавливает. Logout ждёт поздние ответы команд и cleanup. Неопределённый
STOP сохраняет вход и возможность проверки. Потерянный ACK записи требует
явного DATA reconciliation, которое не выдаёт управление.

Свежие observation JPEG заменяются в существующем DOM. Обычный refresh не
пересоздаёт кнопки и не отодвигает срок следующего кадра. Кадр остаётся видимым
при прокрутке панели; скрытый/не загруженный кадр не обновляет наблюдение.

Проверено actual Firefox desktop1440 и mobile390: настоящий central/Node HTTP,
исходные Station worker/recorder, generated JPEG и fake buses. Это software
proof, **не физическая демонстрация или успешный навык**. 268 Node и26 Python
PASS; ошибки предыдущих прогонов и raw сохранены.
