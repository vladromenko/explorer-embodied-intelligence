# Первая настоящая запись — SO-101 Studio

1. Открыть **http://192.168.0.168:8020** из LAN или **http://100.95.83.3:8020** через Tailscale. Обновить страницу ⌘R. В конце приёмки оставлен настоящий camera-only preview; если картинок нет — «Подключить камеры».
2. Нажать **«Проверить перед записью»**. Нужен `READY_FOR_OPERATOR_START`: две камеры и обе руки доступны, место есть, снимки калибровки целы. GPU может быть занят: это не блокирует raw-запись. При `WAITING_FOR_HARDWARE` Preflight показывает владельца PID/устройство; завершить его сессию штатно и проверить снова.
3. Оператор рядом с роботом, свободная рабочая зона, доступен аппаратный STOP. В read-only проверке follower уже имел Torque_Enable=1; инженерный тест его не менял. Двигать робот и проверять следование будет оператор через UI.
4. Выбрать **«Новый датасет»**, произвольное имя, задачу (например `Pick up the cube and place it into the box`), **1 эпизод**, 30–60s. Технический источник скрыт и не должен использоваться для демонстраций.
5. **«Начать запись»** разрешает открытие servo bus и torque. Снимки калибровки сравниваются с live registers до управления. Аккуратно проверить направление каждого сустава и gripper. При неожиданном поведении — STOP; для потери связи/неподтверждённого torque использовать аппаратный STOP.
6. **«Сохранить эпизод»** завершает текущую запись. **«Перезаписать»** сохраняет плохую попытку в quarantine. **«Следующий эпизод»** добавляет новый. **«Остановить»** завершает сессию; backend не зависит от вкладки. Во время паузы сама сессия ещё активна — для окончания используйте «Остановить».
7. В **«Датасеты»** открыть эпизод: оба ракурса, слайдер и **«Воспроизвести»**. Нажать **«Проверить данные»**, затем **«Завершить и сохранить LeRobot»**. Эти CPU jobs доступны без свободного GPU. Валидатор проверяет hash, schema, timestamps, images/state/actions; неполное/повреждённое не становится готовой демонстрацией.
8. После контрольного эпизода записывать новые демонстрации; оба raw ракурса всегда сохраняются. Для train+validation нужно минимум2 целых группы, для отдельного test минимум3. Предпочтительны разные сессии. Число51 хранится как51.
9. **«Обучение» → датасет → SAM-разметка** (если нужны SAM inputs). Дождаться completed_frames=total_frames; смотреть ambiguous/color unknown. Класс/цвет SAM не идеальны, XYZ/depth не выдумываются. При занятости GPU задача ожидает.
10. Выбрать **ACT** (с нуля, текст не читает) или **SmolVLA** (локальный pretrained), baseline или SAM inputs. Задать выборки/параметры, **«Проверить выборки» → «Начать обучение»**. Папка вывода ограничена models этой лаборатории; под неё создаётся отдельный job-id.
11. Метрики: **http://192.168.0.168:5020** или **http://100.95.83.3:5020**. Checkpoint: `models/<job-id>/checkpoints/step_.../` целиком с processors и training_state. Чтобы продолжить завершённый train, выбрать полную папку в Resume и увеличить итоговый Steps.
12. Только после настоящего обучения — **«Политика» → checkpoint → «Проверить загрузку»** без движения. Физический Start — отдельное действие с оператором. Технические acceptance checkpoints скрыты и запрещены для робота. SAM+VLA live может превысить возраст наблюдения2s; guard не обходится, качество захвата ещё нужно доказать физическими испытаниями.

## Короткая проверка Safari с Mac — пока NOT TESTED

- LAN и Tailscale URL открываются, без запроса камеры самого Mac и без navigator.mediaDevices error.
- Видны реальные top/wrist; camera-only отключается и подключается, руки при этом не управляются.
- Имя/задача вводятся полностью; выбор51 не обрезается; ошибки понятны.
- Закрытие/возврат вкладки восстанавливает статус серверной сессии; отключение связи не теряет raw.
- Playback двух ракурсов, ACT/Smol выбор, Preflight и MLflow открываются.

Только HTTP/WS реально настроены на8020/5020. HTTPS/WSS не заявляются пройденными; серверное изображение не требует secure-context mediaDevices.

## Освобождённые соседние службы

По разрешению пользователя остановлены user `so101-wristlab-web`, system `so101-pick-place` и `lelab`. Их enablement/config не менялись. Не запускать их одновременно с нашей записью/preview/обучением, если они занимают те же ресурсы. Для возврата к тому эксперименту сначала остановить нашу сессию и отключить камеры, затем пользователь может вернуть нужную службу: `systemctl --user start so101-wristlab-web` либо `sudo systemctl start so101-pick-place lelab`.
