# Fresh TARGET visual student

`scripts/run_sim_object_learning.py` фиксирует отдельный протокол до запуска.
Все эпизоды — SIM; источник геометрического учителя явно `SCRIPTED_SIM`.
Это обучение целевого visual ACT9, не доказательство learned source04/H2.

`freeze` сохраняет 20 проверенных CAD, исходный шаблон, калибровку, SHA кода,
геометрию train/development/sealed и оба варианта chunk1/chunk8. `teacher`
разрешён только для train. Полные contact/settle/retreat исходы проверяются
независимым неизменённым evaluator и фактическим открытием захвата в SIM.
Неудачи сохраняются; в `dataset` проходят только полные train-эксперты.

`smoke` делает 8 настоящих обновлений только для интеграции. `train` отдельно
делает заранее фиксированные 1200 обновлений official LeRobot ACT на CPU.
RGB и буквальная предыдущая команда9 — единственные входы сети. Фазы, truth,
геометрия учителя и evaluator доступны только для labels/оценки. После
save/reload фиксируются один checkpoint и оба диспетчера, затем идут paired
development и единственная paired sealed-серия без тюнинга по sealed.

Каждый этап запускается новым процессом в собственном ограниченном unit.
EGL используется только для изображений; CUDA-обучения нет. Полный ROSMASTER
9D сохраняется, включая валидные нейтральные каналы шасси. Неподвижность базы
— явно проверенный weld SIM, а не отдельный arm-only тип робота.
Даже полный успех здесь не означает навигационную или физическую готовность.
