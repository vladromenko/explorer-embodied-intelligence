# Независимое программное ревью подключения ввода

Проверены исходники `11ab483` / `293ff9f` в отдельном worktree Homebrain.
Обнаружены и воспроизведены два дефекта:

1. Параллельные `keyboard.start()` и `browserGamepad.connect()` могли оба завершиться
   успешно: оба браузерных контроллера оставались active и каждый отправлял свою
   последовательность select/input/resume. Проверка отдельного контроллера не
   обнаруживала гонку между двумя app-hooks.
2. Logout удалял session/CSRF до pagehide cleanup; последующий штатный STOP мог
   отвергаться сервером. Watchdog не заменяет подтверждённый STOP при выходе.

Root исправил оба в `2f715a5`: единый токен до первой асинхронной подготовки,
проверка владельца после ожиданий, ожидание завершения предыдущего клиента;
freeze подключения во время STOP/logout и drain/STOP до удаления credentials.
Неопределённый STOP сохраняет вход. Дополнительная проверка точного пути
`/api/robot/teleop/controls` подтвердила, что он уже покрыт bounded fetch;
сообщённое предварительно подозрение о другом пути снято.

На `2f715a5` выполняются 17 Node проверок `tests/test_app_bootstrap.js`.
VM загружает **все реальные deferred scripts из index.html в их порядке**, а не
выбранные вырезки функций. Проверены bootstrap `/`,01,02,03,04,06 и старый lab URL;
оба порядка конкурентного подключения; blur/STOP при задержанном native resume
обоих источников; logout при задержанном select; запрет нового подключения при
выходе; сохранение credentials при неудаче STOP; задержанный настоящий controls GET
с последующим выбором клавиатуры или blur. Поздний ответ не создаёт select/resume
после отмены. Bootstrap не делает управляющих запросов. Все ответы и DOM/таймеры
изолированы в памяти; ни один URL не передаётся сетевому клиенту ОС.

Три ASGI проверки `tests/test_camera_proxy_security.py` используют только временную
SQLite и `httpx.MockTransport`: без сессии upstream не вызывается; JPEG + исходные
X-Frame заголовки сохраняются, bearer/internal headers не выходят наружу;
CSRF/cross-origin отказ наступает до любого upstream; валидный logout делает
следующий camera GET неавторизованным. У mock upstream разрешены только camera GET.

Это подтверждение программного lifecycle и маршрутов на указанном commit, а не
квалификация настоящего Mac Gamepad API, размеров/поведения DOM или физического
управления. Обе руки и шасси при этих проверках не подключались и не двигались.
