# Explorer: интерфейс общей станции

Статический интерфейс обслуживается FastAPI с `/static`. `index.html` — общая оболочка для `/`, `/experiments/01`…`05`, `/research`, `/skills`, `/infrastructure`, `/learning/so101`; `login.html` обслуживается через `GET /api/login`.

Все изменения отправляются с cookie сессии и `X-Explorer-CSRF` из `explorer_csrf`. Пароль передаётся JSON-запросом в `POST /api/login`, не сохраняется интерфейсом. Внешние шрифты, изображения и CDN не используются.

Камеры показывают настоящий MJPEG; при ошибке — снимки с API. Неуспешный кадр скрывается, последние изображения не выдаются за свежие. Кадр симуляции появляется только при фактическом `frame_available`. Числа и графики не генерируются из примеров.

Записи наблюдения используют `/api/recordings`. Они явно отделены от обучающих эпизодов. Личная лаборатория использует `project_id=personal`.

Страница 02 также использует штатный мост ROSMASTER `/api/robot/teleop/*`, `/api/robot/teaching/mobile/*`. Активация клавиатуры требует полученного кадра сцены и штатной раскладки. События клавиш передаются только после явного включения управления, с частотой до 10 Гц; обычное отпускание отправляет текущий набор клавиш, включая пустой. Потеря фокуса, скрытие страницы, уход в другой раздел, Space/Escape передают нейтральный ввод и штатный STOP. Возврат фокуса не возобновляет управление. Режимы — `cartesian` и `joint` (точная схема установленной реализации). Формы и диалог записи не перехватывают клавиши движения.

Полный показ использует существующий `explorer_mobile_episode_v3`, heartbeat с `active.session`, оценку оператора `success|failure|unknown`. Эта отметка не выдаётся за независимую физическую приёмку. Командная оценка суставов подписана отдельно от измеренного состояния.

Общая кнопка STOP вызывает `/api/stop`: backend обязан передать штатный STOP роботу и отменить программные задачи; ответ `robot_error` показывается как неподтверждённая остановка робота.

Интерфейс не добавляет настройки безопасности, не меняет контроллер и не отправляет ROS-команды напрямую. Готовность автоматических навыков и условия наблюдения выводятся из `/api/state.admission`; существующая ручная панель доступна по отдельной ссылке.

Проверки: синтаксис обоих JS-файлов; обработчики используют реальный зафиксированный API. Визуальная проверка браузером на этапе подготовки недоступна: Mac заблокирован, CUA не видит браузеров. После интеграции нужна проверка внешнего вида и действий на реальном backend.
