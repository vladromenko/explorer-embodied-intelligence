# Мастер полного показа

`explorer.demonstration_wizard` формирует следующий небольшой шаг по сохранённым
свидетельствам. Он не записывает движение, не меняет допуск обучения и не
подтверждает владение навыком.

План включает подготовку сцены, последовательность фаз, подсказки по управлению,
число просмотренных оригинальных эпизодов, отдельные неудачи/неизвестные исходы,
охват направлений, сцен, сессий и предметов. Успешный первый захват не заменяет
подъём, перенос, отпускание и устойчивое завершение задачи.

Рекомендация сначала предлагает разобрать уже перенесённые записи. При отсутствии
записей предлагает технический набор из трёх попыток; при сбоях это можно довести
до пяти технических попыток. Затем решение зависит от пригодности данных,
неудач, непокрытых условий и отдельных попыток модели. При достаточном пилотном
охвате мастер предлагает проверку вместо бесконечного накопления одинаковых
показов. Указанная серия — ориентир для следующего решения, а не число для
гарантированного освоения задачи.

Источники — только завершённые `station_import`/`mobile_import` в текущем проекте.
Проверяются хеши преобразованных эпизодов и сохранённых исходников. Сегменты
одного оригинала и повторный импорт не увеличивают число показов. Исходы `failure`
и `unknown`, прерванные записи, непригодные метки и закрытые тесты не увеличивают
охват одобренных учебных показов. Явная отметка оператора не изменяет исходную
метку или исходный допуск обучения.

Для тенденции результатов используются отдельно сохранённые `station_rollout`:
требуются настоящие журналы наблюдений, совпадающие хеши кадров и фактические
servo-loop dispatch receipts. Shadow не становится попыткой выполнения. Полный
итог отмечает оператор после просмотра. Совпадение независимых scene/session
splits автоматически не устанавливается; это явно отражено в ответе API.

Разбор хранится как неизменяемое событие `demonstration.review` в существующей
SQLite WAL. Исправление требует SHA предыдущей версии и сохраняет историю.
Устаревшая версия клиента не может затереть новый разбор. Изменение исходных
байтов исключает прежний разбор из охвата до повторной проверки. Новых таблиц,
файлов с калибровками или настроек контроллера не создаётся.

## Подключение интегратором

В `app.py` под существующей аутентификацией и CSRF:

```python
@app.get('/api/demonstration-wizard')
def demonstration_plan(project_id: str, task_id: str = 'pick_and_place'):
    from .demonstration_wizard import plan
    try:
        return plan(STORE, project_id, task_id)
    except ValueError as error:
        raise HTTPException(400, str(error))


@app.post('/api/demonstration-wizard/annotation')
async def demonstration_review(request: Request):
    from .demonstration_wizard import annotate
    body = await request.json()
    try:
        return await asyncio.to_thread(annotate, STORE, body.get('project_id'), body.get('task_id'), body)
    except ValueError as error:
        raise HTTPException(409, str(error))
```

Подключить `/static/demonstration-wizard.js` с `defer` перед `app.js`.
На страницах 02, 03 и личной лаборатории добавить
`demonstrationWizardPanel(projectId)` после существующего блока записи.
Функция получает данные из API при первом открытии; кнопка «Обновить» перечитывает
импорты и план. Поля разбора сохраняются при регулярной перерисовке страницы.
Все пользовательские строки проходят HTML escaping. Скрипт не обращается к
командам записи, станции, ROSMASTER или движения.

## Проверки

`python -m pytest tests/test_demonstration_wizard.py -q`: 14 passed на Homebrain.
Проверены неполная задача, неизвестные/повторные фазы, контроль целостности,
независимость проектов, подсчёт оригиналов, held-out и ошибочные источники,
история исправлений, устаревшие SHA, меняющаяся рекомендация и минимальный UI
путь с точным запросом сохранения. Отдельный read-only запуск по фактическому
центральному хранилищу обнаружил три непроверенных оригинала проекта 02 и один
личной лаборатории; одобренных полных показов без разбора не создаётся.

Это инженерная проверка планировщика/интерфейса. Физическое освоение объектов,
качество обученной политики и гипотезы H1–H5 ей не подтверждаются.
